# Message.Me

Учебный сайт вопросов и ответов для курса VK Education.

## Как открыть вёрстку

Откройте `public/index.html` в браузере. Bootstrap, стили, скрипты и изображения хранятся в `public/static/`.

| Файл | Страница |
| --- | --- |
| `public/base.html` | Общий макет |
| `public/index.html` | Новые вопросы |
| `public/hot.html` | Популярные вопросы |
| `public/tag.html?tag=django` | Вопросы по тегу |
| `public/question.html?id=1` | Вопрос и ответы |
| `public/ask.html` | Создание вопроса |
| `public/login.html` | Вход |
| `public/signup.html` | Регистрация |
| `public/profile.html` | Настройки профиля |

Поиск, пагинация и голоса работают на демонстрационных данных в браузере. Формы показывают поля, подсказки и примеры ошибок.
